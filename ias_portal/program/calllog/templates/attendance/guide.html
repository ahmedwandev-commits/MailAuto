اليوم القوى العاملة › اليوم

  • اختار اليوم{% if not who.manager %} والفريق{% endif %} من فوق.
  • الكروت بتوضح مين متوقع، مين وصل، ومين لسه. اضغط فريق لتفاصيله، أو اسم موظف للوحته.
  • «محتاج انتباه»: اللي ما وصلش واللي محتاج إذن.
    • {% if who.writer or who.affairs %}
  • تعديل الورديات من الزرار فوق لتعديل يوم موظف بسرعة.
    • {% endif %}
  • قبل رفع شيت الموارد البشرية لليوم، اللي فتح البوابة بيظهر «وصل» كعلامة إنه بدأ شغل بس؛ الحساب الرسمي من الشيت.

جدول الفريق القوى العاملة › الجدول › جدول الفريق

المدير يبني الشهر←المدير العام يعتمد = رسمي فورًا←الشئون الإدارية: الليلي والعطلات + الإيميل
{% if who.manager or who.admin %}

مدير الفريق

  1. اسحب اسم الموظف للوردية (على الموبايل: دوس الاسم ثم الوردية). تقدر تحط نفسك كمان.
  2. باقي الأسبوع ينسخ اليوم لباقي الأسبوع، وانسخ الأسبوع الأول لكل الأسابيع للشهر كله.
  3. حفظ ثم إرسال للمدير العام. لو اترجع لك، الملاحظة بتظهر فوق: عدّل وابعته تاني.
{% endif %} {% if who.gm or who.admin %}

المدير العام

  1. افتح الفريق من جدول الفريق. تقدر تنقل الموظفين وتدوس حفظ.
  2. اعتماد: الجدول يبقى رسمي على طول. أو اكتب ملاحظة ودوس إرجاع.
{% endif %} {% if who.office %}

الشئون الإدارية

  1. أضف العطلات الرسمية للشهر (محدش بيتحط فيها).
  2. افتح أي فريق وحط الليلي والإجازة (الخانتين دول ليك انت بس).
  3. بعد اعتماد كل الفرق: إرسال إيميل الجدول (العناوين من الإعدادات).
  4. النشر من جديد بيحل محل الشهر كله.

حضوري: الأوفر تايم والبدل المتوقع القوى العاملة › حضوري

  • بتشوف شهرك انت بس، في 3 تبويبات: الحضور · بدل الورديات · الوقت الإضافي.
  • كل الأرقام من شيت الموارد البشرية اللي بيرفعه الأدمن. اليوم اللي شيته لسه ما اترفعش بيظهر «في انتظار شيت الموارد البشرية» ويتحسب متوقع من جدولك لحد ما يترفع.
  • الورديات المحسوبة بالعدد (صباحي · مسائي · ليلي · عطلة) من غير أي مبالغ.
  • الوجبات: الصباحي فطار، المسائي غدا، الليلي عشا - من أول {{ num(ot.base_hours) }} ساعات. ولو قعدت {{ num(ot.long_day_hours) }} ساعات أو أكتر وجبة إضافية.
  • يوم الإجازة لو اشتغلت فيه: وجبة حسب وقت حضورك.
    • {% if who.manager %}
  • المشرف: الوردية الصباحية بس (والعطلات) مع الفطار، والوجبة الإضافية لو قعد {{ num(ot.long_day_hours) }} ساعات.
    • {% endif %}
  • ده تقدير؛ البدل الرسمي هو اللي بيتعزز آخر الشهر.
  • بيبدأ بعد {{ num(ot.base_hours) }} ساعات شغل. قبل {{ ot.evening_from }} ×{{ num(ot.day_rate) }}، من {{ ot.evening_from }} لـ {{ ot.night_from }} ×{{ num(ot.evening_rate) }}، بعد {{ ot.night_from }} ×{{ num(ot.night_rate) }} (لحد {{ ot.night_until }}، ولحد {{ ot.night_until_rest }} صباح الجمعة والسبت).
  • يوم راحة أو عطلة اشتغلت فيه: لو أخدت بدل راحة في يوم شغل (الأحد للخميس) بعده في نفس الأسبوع أو الأسبوع اللي بعده = مفيش أوفر تايم، بدل الانتقال بس. لو لأ = كل ساعة ×{{ num(ot.holiday_rate) }}. الجمعة أو السبت اللي بعدها مش بدل راحة.
  • بيتخصم {{ num(ot.weekly_deduction_hours) }} ساعة كل أسبوع، والحد الأقصى {{ num(ot.cap_pct) }}% من {{ num(ot.base_days) }} يوم × {{ num(ot.base_hours) }} ساعات ({{ num(ot.base_days * ot.base_hours * ot.cap_pct / 100) }} ساعة).
{% if who.manager %}
  • تبويب الفريق: نفس الأرقام لكل فرد في فريقك، مرتبة بالأوفر تايم.
{% endif %}

جدولي القوى العاملة › جدولي

  1. شوف ورديات الأيام الجاية والشهر.
  2. آخر الشهر: تعزيز بدل ورديتي أو اعتراض مع كتابة السبب.
  3. نسيت بصمة؟ هيوصلك تنبيه وإيميل. لو حاجة غلط كلّم مديرك.

الاستيراد القوى العاملة › الاستيراد

  1. الحضور (الموارد البشرية): ارفع ملف الإكسل - يوم أو يومين أو أسبوع مرة واحدة - وبيتستورد على طول، وكل الحسابات بتتحدث.
  2. اللي ناسي بصمة حضور أو انصراف يوصله تنبيه وإيميل، ومديره يوصله إيميل بأسماء فريقه.
  3. أرقام الموارد البشرية: لو رقم في الملف مش مربوط بحساب، اربطه مرة واحدة.
  4. الجدول الشهري (رفع الإكسل) وربط الأسماء وسجل الاستيراد.

الإعدادات {% if who.admin %}الإدارة › الإعدادات{% else %}إعدادات الحضور{% endif %}

  • القواعد والبدل: مديرو الفرق، بدل الورديات (المبلغ لليوم)، الوقت الإضافي والوجبات، إيميل جدول الفريق، قواعد الحضور، أنواع الورديات، العطلات، أنواع الإجازات.
  • الموظفون والفرق: فريق كل شخص في القوى العاملة (فريق واحد)، واللي مالوش فريق بيظهر فوق.
  • قواعد التقييم، الأدوار والصلاحيات، وسجل التدقيق.
    • {% if who.admin %}
  • من الإدارة › المستخدمين: الدور (موظف / مدير / شئون إدارية / أدمن) والفريق - مفيش حساب من غير فريق.
    • {% endif %}
  • لو حساب عليه فريقين (للبريد)، اختار فريقه في القوى العاملة من القائمة.
