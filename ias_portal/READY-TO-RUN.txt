IAS PORTAL - READY TO RUN (your own data is inside)
=============================================================

This package holds the new program AND everything of your running NBE OpsHub: the data folder (users,
roles, teams, passwords, settings, auto-assign rules, history), .secret_key, collector_config.json (the
SSO-portal and ITSM accounts) and libs. Keep it private - it carries your collector passwords.
Your copy was taken on 25 Oct 2026, 06:12.

A NEW FOLDER OR A NEW PC
  1. Copy everything inside "program" into the folder (e.g. the shared folder).
  2. Start run.py, then collector.py. Everyone signs in with the same user ID and password as before.
     (libs is already complete - no internet needed.)

THE SAME FOLDER AS THE OLD VERSION
  1. Stop the old run.py and collector.py.
  2. Copy everything inside "program" over the old folder.
     If the old version was used after 25 Oct 2026, 06:12, do NOT copy the "data" folder: yours is newer and
     the new version uses it as it is (the format is the same).
  3. Start run.py, then collector.py.  Check the collector with:  python collector.py --check

THE DAILY SUMMARY IS OFF IN YOUR SETTINGS (NBE OpsHub had none): System > Settings > Daily summary - switch it on,
type the To addresses, Save, then press "Run now" there to try it.
